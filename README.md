# 🔐 Login and Registration System

## 📌 About
A simple Python-based Login and Registration System that allows users to create an account and log in using their username and password.

This project is created to practise Python fundamentals and understand basic user authentication.

## ✨ Features
- User Registration
- Username Availability Check
- Password Validation (minimum 6 characters)
- Confirm Password During Registration
- Login Authentication
- Maximum 3 Login Attempts
- Empty Username Validation
- Remove Extra Spaces from Usernames
- Exit Option

## 🛠️ Technologies Used
- Python 3

## ▶️ How It Works
1. Select Register to create a new account.
2. Enter a unique username.
3. Create a password with at least 6 characters.
4. Confirm your password.
5. Select Login to access your account.
6. Enter the correct username and password.

- While Loops
- If-Else Conditions
- Nested Loops
- String Methods (`strip()`)
- Input Validation
