🔐 Login & Registration System

A simple Login and Registration System built using Python. This beginner-friendly project allows users to register an account and log in using their username and password.

🚀 Features

- 📝 User Registration
- 🔑 User Login
- 💾 Stores user details in a text file
- ❌ Invalid login detection
- 🚪 Exit option
- 📚 Beginner-friendly Python code

🛠️ Technologies Used

- Python
- File Handling
- Loops
- Conditional Statements
- User Input

▶️ How to Run

1. Make sure Python is installed.
2. Download or clone this project.
3. Open the project folder in VS Code or Command Prompt.
4. Run:

python login_registration.py

5. Choose an option from the menu.

📂 Project Structure

Login-Registration-System/
│
├── login_registration.py
├── users.txt
└── README.md

«"users.txt" is created automatically when a user registers.»
